# Pixel MiPushFramework 交接

## 当前主线

维护 Pixel 上的小米共享推送服务，使用独立版本线。当前基线包含 `v1.0.1` 的日志脱敏和首页调整。Android 系统行为迁移另开主题分支，保留现有推送能力。

- [BUILDING](../BUILDING.md)：工具链、产物检查和 CI，版本参数以构建文件为准。
