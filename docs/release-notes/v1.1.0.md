Android 17（target 37）首个正式版：界面现代化及返回手势动效按 Pixel Text 标准对齐完成，普通默认通知点击在真机验收通过。当前 alpha.8 设备可直接更新到本版。

> **适配范围**：以 Pixel 设备为核心做适配与体验打磨，其他机型不保证效果。

## 新功能

- **Android 17 适配**：target 37、edge-to-edge、预测性返回与 POST_NOTIFICATIONS 运行时授权流程；前台连接服务以 specialUse 类型声明
- **Pixel Text 动效**：页面转场对齐整页位移、FastOutSlowIn 缓动、前后景缩放与错开淡化时序；底栏栏目切换保持固定外壳与内容淡入淡出
- **统一次级导航**：高级设置、应用详情、近期记录、帮助与记录详情进入主导航，共享分层滑动与预测性返回进度转场

## 问题修复

- **返回手势进度响应**：原弹簧曲线小幅拖动即近全屏滑出，按样版参数整套修正后跟手观感经真机验收通过
- **普通默认通知点击**：原 Service 中转在 target 37 受后台启动限制，改为通知点击 Activity 入口，真机验证新消息点击进入对应聊天并清理通知
- **迁移遗留**：新通知备份格式 immutable 化，首次迁移不恢复旧临时备份；移除未使用的旧动效路径与无调用绑定辅助

## 安装

- 使用 `PixelMiPushFramework-normal-universal-1.1.0.apk`；特殊系统（已知 COS）改用 `PixelMiPushFramework-vc105-universal-1.1.0.apk`
- 同签名覆盖安装即可，注册状态与推送记录保留；其他来源签名需先卸载，数据清除

## 已知问题

- 自定义局域网推送服务器需本地网络授权，本轮尚未适配
- SDK 商业消息路径、独立注册／ACK 回执及无授权环境后台恢复延续既有边界，未逐一重测
