Android 17（target 37）首个正式版：界面与现代动效适配完成，普通默认通知点击真机验收通过。

> **适配范围**：以 Pixel 设备为核心打磨，其他机型不保证效果。

## 新功能

- **Android 17 适配**：target 37、edge-to-edge、预测性返回与 POST_NOTIFICATIONS 授权流程；前台服务声明 specialUse
- **现代动效**：页面转场对齐整页位移、缓动、前后景缩放与错开淡化时序；底栏栏目切换保持固定外壳与内容淡入淡出
- **统一次级导航**：设置、应用详情、近期记录、帮助与记录详情进入主导航，共享分层滑动与进度转场

## 问题修复

- **返回手势进度响应**：原弹簧曲线小幅拖动即近全屏滑出，按样版参数整套修正后跟手观感通过真机验收
- **普通默认通知点击**：原 Service 中转受后台启动限制，改为通知点击 Activity 入口，真机验证点击进入对应聊天并清理通知
- **迁移遗留**：通知备份格式 immutable 化，首次迁移不恢复旧临时备份；移除未使用的旧动效路径

## 安装

- 使用 `PixelMiPushFramework-normal-1.1.0.apk`；特殊系统（已知 COS）改用 vc105 附件。同签名覆盖安装即可，注册状态与推送记录保留；其他来源签名需先卸载，数据清除
