## 新功能

- **通知授权**：引导页加入通知授权，拒绝后可进入系统通知设置，返回时更新授权状态。

## 问题修复

- **授权后启动**：完成引导后再次启动推送连接，处理首次授权前启动未成功的恢复点。
- **前台连接声明**：补齐新版系统要求的前台服务类型、权限和具体用途。

## 改进

- **系统适配**：目标提升到 API 37，保留既有推送 SDK、数据库、页面导航和系统栏适配。

默认 Service 通知点击仍待最终设备定位，已有直接 Activity 路径的 target 31 结果不能替代 target 37 验收。自定义局域网服务器所需的新授权尚未适配。

首次从旧格式迁移时，临时通知备份无法自动恢复。注册数据与推送历史存储格式保持原样。

完整记录及边界见 [Android 17 迁移记录](https://github.com/huaxianyan/PixelMiPushFramework/blob/v1.1.0-alpha.3/docs/ANDROID17-MIGRATION.md)。
