## 问题修复

- **默认通知点击**：普通推送改由通知点击页面承接，保留应用打开、原消息转发及通知清理流程，待真机确认。
- **底栏切换**：固定同级栏目的顶栏和底栏，只切换内容，层级页面继续使用分层滑动。
- **事件页系统栏**：修复应用事件详情页缺少系统栏留白的问题，页头和列表使用页面自己的布局边界。
- **搜索与滚动布局**：补齐搜索页面的键盘留白，长页面滚动内容可以延伸到系统栏下方。

已有 Material You、可调整窗口与预测性返回接入保持稳定版本。此次集中验证手势进度、取消、提交及页面返回，尚未据此宣布视觉验收通过。

升级前普通默认通知的旧点击入口需要新通知替代。已验证的 QQ 直接点击配置保持原样；SDK 商业消息仍走原 SDK 处理器，尚未完成该路径迁移。

注册数据、推送历史、原 SDK 和签名保持原样。局域网自定义服务器与独立 ACK 等边界仍未闭环。

完整记录及验收边界见 [Android 17 迁移记录](https://github.com/huaxianyan/PixelMiPushFramework/blob/v1.1.0-alpha.4/docs/ANDROID17-MIGRATION.md)。
