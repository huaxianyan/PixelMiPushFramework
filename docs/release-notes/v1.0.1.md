修复日志中凭据明文的问题，并简化首页信息。推送链路保持原样，主要面向 Pixel 设备。

## 问题修复

- **日志凭据明文**：统一日志出口脱敏，保留字段名与行结构，覆盖 logcat、应用日志、崩溃报告及桥接的 SDK 日志。设备标识仍保留用于排障。

## 改进

- **首页信息**：移除设备标识，补充服务运行时长，移除连接卡中重复的计时信息。

优先使用 normal 附件；已知 COS 系统无法通过 bind 传递消息时选择 vc105。同签名覆盖安装保留注册状态与推送记录；其他签名需先备份并确认重装方案，卸载会清除原数据。

已知问题：补收消息沿用原时间戳，重连退避上限 5 分钟，前台服务默认关闭。
