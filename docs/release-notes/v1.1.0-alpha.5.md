Android 17 导航修复预发布，统一应用内次级页面的跟手返回，并恢复底栏内容切换动效，等待最终附件真机验收。正式使用请继续选择 v1.0.1。

## 问题修复

- **次级页面返回**：应用内高级设置、应用详情、近期记录和帮助进入同一层级导航，统一分层滑动与预测性返回。
- **底栏切换**：顶栏、底栏保持固定，中间内容恢复轻量淡入淡出；同级切换与层级返回分别处理。

系统“管理存储空间”仍使用原高级设置外部入口，与应用内高级设置共用页面。系统设置和浏览器等应用外页面继续使用系统转场。

保留 alpha.4 的系统栏、键盘与默认通知点击改动。SDK 商业消息、独立 ACK 和局域网服务器等边界仍未闭环，尚未宣称完整适配通过。

注册数据、推送历史、原 SDK 和签名保持原样。旧版普通默认通知需由新通知替代后测试。

完整记录及验收边界见 [Android 17 迁移记录](https://github.com/huaxianyan/PixelMiPushFramework/blob/v1.1.0-alpha.5/docs/ANDROID17-MIGRATION.md)。
