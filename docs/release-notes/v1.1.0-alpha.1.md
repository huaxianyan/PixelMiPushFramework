## 问题修复

- **服务启动设置**：修正启动方式与前台通知开关不一致的问题，服务再次启动时应用当前设置。

## 改进

- **通知备份**：采用新格式，适应新版系统要求。实际更新恢复待设备验收。
- **页面转场**：主页及帮助页使用不透明分层滑动，返回手势交给现有导航组件处理。实际手势效果待设备验收。

默认通知点击仍可能经 Service 打开应用，这条路径尚未解决 target 31 的中转限制。后台恢复、首次省电授权后的定时调度及真实推送也尚未验收。

首次从旧版迁移时，旧格式临时通知备份无法自动恢复。注册数据和推送历史的存储格式保持原样。
