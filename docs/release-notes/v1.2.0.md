新增模块状态与个性化设置，优化历史记录的分批加载和滚动浏览。

## 新功能

- **模块状态**：首页显示推送服务、系统通知增强及个性化项目汇总，区分正常、未就绪与待检测
- **QQ 通知定制**：通过模块设置中的独立页面控制角标、会话头像和汇总副标题清理，关闭选项不计为故障

## 问题修复

- **首刷重复加载**：修复界面重组时可能重复发起历史查询的问题，避免加载任务叠加
- **列表末尾重复请求**：识别末页并停止后续请求，加载失败时保留已显示内容并提供重试

## 改进

- **历史浏览**：每批读取 20 条，接近末尾时预取更早记录，后台完成读取与解析，保留搜索和下拉刷新
- **项目说明**：README 改以本项目的维护内容为主，安装兼容与来源说明分别归入独立文档

模块设置需搭配 Pixel MiPush v1.1.0，模块更新后按管理器提示重启。包名、SDK、schema 和长期签名保持不变，既有未测边界继续保留。

完整实现与验证范围见 [开发记录](https://github.com/huaxianyan/PixelMiPushFramework/blob/v1.2.0/docs/STATUS.md)，遵循上游 GPL-3.0 许可与署名。
