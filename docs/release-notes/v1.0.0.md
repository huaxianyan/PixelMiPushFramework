Pixel MiPushFramework 首个正式版本，启用独立版本线，不再沿用上游 0.3.x 编号。主要面向 Pixel 设备，其他机型尚未充分验证。

## 新功能

- **Material 3 界面**：新增仪表盘启动页、两级推送记录和单页权限引导，Android 12+ 支持动态取色。
- **签名发布**：Release 使用项目独立签名，打标签后自动构建、校验和发布。

## 问题修复

- **网络切换后长时间收不到推送**：启用 SDK 既有连接超时看门狗，处理连接状态卡住、后续重连请求被丢弃的问题。两次独立故障注入验证通过。
- **页面显示**：修正配置目录多余空格、服务器行空行和状态卡重复 IP，统一界面组件。

优先使用 normal 附件；已知 COS 系统无法通过 bind 传递消息时选择 vc105。支持 Android 6.0 及以上，首次安装按应用内引导授权。

本项目签名与上游不同。已有其他签名的安装时，先备份注册信息与推送记录，再确认卸载重装方案；卸载会清除原数据。

已知问题：补收消息沿用原时间戳，重连退避上限 5 分钟，前台服务默认关闭。

完整变更与历史验证见 [原始发布记录](https://github.com/huaxianyan/PixelMiPushFramework/blob/v1.0.0/docs/release-notes/v1.0.0.md)。
